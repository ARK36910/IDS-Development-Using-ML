# Machine Learning-Based Intrusion Detection System

A machine learning-based Intrusion Detection System (IDS) using the **UNSW-NB15 dataset** to classify network traffic as **Normal** or **Attack**.

The project compares three tree-based machine learning models:

* Decision Tree
* Random Forest
* Extra Trees

It also includes data preprocessing, exploratory data analysis, model evaluation, confusion matrices, feature importance, and sample traffic prediction.

## Dataset

This repository does **not** include the UNSW-NB15 dataset.

Download the official UNSW-NB15 dataset and obtain the following files:

* `UNSW_NB15_training-set.csv`
* `UNSW_NB15_testing-set.csv`

Place them in the following directory structure:

```text
IDS-Development-Using-ML/
│
├── Proj8.ipynb
│
└── data/
    └── UNSW_NB15/
        ├── UNSW_NB15_training-set.csv
        └── UNSW_NB15_testing-set.csv
```

The `data/` folder is excluded from the repository because the dataset is large and is not included with this project.

## Requirements

Python 3.x with the following libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn joblib
```

Jupyter Notebook or JupyterLab is also required:

```bash
pip install notebook
```

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/ARK36910/IDS-Development-Using-ML.git
cd IDS-Development-Using-ML
```

### 2. Download the dataset

Download the UNSW-NB15 training and testing CSV files and place them inside:

```text
data/UNSW_NB15/
```

Make sure the filenames match:

```text
UNSW_NB15_training-set.csv
UNSW_NB15_testing-set.csv
```

### 3. Start Jupyter Notebook

Run:

```bash
jupyter notebook
```

Open the project's `.ipynb` notebook.

### 4. Run the notebook

Run the cells **in order**.

The notebook performs:

1. Dataset loading
2. Data preprocessing
3. Categorical feature encoding
4. Exploratory data analysis
5. Decision Tree training
6. Random Forest training
7. Extra Trees training
8. Model evaluation
9. Accuracy, Precision, Recall and F1-score calculation
10. Confusion matrix generation
11. Feature importance analysis
12. Normal/Attack traffic prediction
13. Random sample prediction demonstration

## Generated Files

The notebook creates processed data and model-related output directories during execution.

The `processed` data does **not** need to be downloaded separately. It is generated automatically during preprocessing.

Similarly, any graphs, trained models, or result files produced by the notebook are generated locally when the relevant cells are executed.

## Classification

The IDS performs binary classification:

```text
0 → Normal Traffic
1 → Attack Traffic
```

The Random Forest model can also be used to predict individual network records and display the predicted class and associated probability.

## Notes

* The dataset is intentionally not included in this repository.
* The `processed` folder is also intentionally excluded because it is generated by the notebook.
* Run the preprocessing cells before running the model training and prediction cells.
* Results such as accuracy, precision, recall, and F1-score depend on the dataset and the exact environment in which the notebook is executed.
